Painel Admin

Padaria Vila Nova — ativar/desativar categorias e produtos em lote

A planilha traz uma coluna "Caminho" (não edite essa) que identifica cada produto — com ela, importar passa a atualizar qualquer campo (nome, categoria, preço...), criar produtos novos (linha sem caminho) e desativar os que sumirem da planilha. Se a categoria digitada não bater com nenhuma categoria existente, o produto vai automaticamente para uma categoria "Mix". A coluna Categoria tem um menu suspenso com as categorias existentes (a lista completa fica numa aba separada chamada "Categorias", só como referência — não precisa editar lá); Ativo, EmPromocao e Exposicao também têm menu com Sim/Não. A planilha se atualiza sozinha sempre que algo muda no site (Pages CMS ou este painel) — use "Exportar para o Google Sheets" só se quiser forçar uma atualização imediata.

Cada alteração salva no site vira uma versão. Restaurar volta os arquivos daquela versão para como estavam antes dela — se algum tiver sido alterado de novo depois, essa alteração mais recente também é desfeita (o painel avisa quando isso acontece).
