Painel Admin

Padaria Vila Nova — ativar/desativar categorias e produtos em lote

A planilha agora traz uma coluna "Caminho" (não edite essa) que identifica cada produto — com ela, importar passa a atualizar qualquer campo (nome, categoria, preço...), criar produtos novos (linha sem caminho) e desativar os que sumirem da planilha. No fim da planilha aparece a lista das categorias existentes, como referência — se a categoria digitada não bater com nenhuma delas, o produto vai automaticamente para uma categoria "Mix". A planilha do Google Sheets agora se atualiza sozinha sempre que algo muda no site (Pages CMS ou este painel) — use "Exportar para o Google Sheets" só se quiser forçar uma atualização imediata. "Exportar planilha (CSV)" baixa um arquivo.

Cada alteração salva no site vira uma versão. Restaurar volta os arquivos daquela versão para como estavam antes dela — se algum tiver sido alterado de novo depois, essa alteração mais recente também é desfeita (o painel avisa quando isso acontece).
